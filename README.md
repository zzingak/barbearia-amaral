# Barbearia - Sistema de Agendamentos

Projeto em construção por etapas. Parte (a): base do projeto e banco de dados.

## Comandos principais
- `npm install`        instala as dependências (só na primeira vez)
- `npm run db:push`    cria as tabelas no banco
- `npm run db:seed`    cria os dados de demonstração
- `npm run dev`        liga o site em http://localhost:3000
- `npm run db:studio`  abre uma tela para ver os dados salvos
- `npm run db:reset`   APAGA tudo e recria os dados de demonstração

O passo a passo completo para Windows está em `docs/INSTALACAO-WINDOWS.md` (Etapa 4).
